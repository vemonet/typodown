Seamless markdown editing,
everywhere you write.

Typodown blends reading and writing into one continuous motion. Markdown renders where you type: no preview pane, no markup cluttering the page.

Open-source & cross-platform, inspired by Typora.

VSCode extension Desktop app Android app npm package
npm i --save @vemonet/typodown

👀 WYSIWYG editing

Edit rendered markdown directly. Raw markers surface only on the block you edit.

🐙 GitHub Flavored Markdown

Alerts, checkboxes lists, editable tables, YAML front matter and raw HTML.

📈 Math & diagrams

Inline and block LaTeX, plus live Mermaid diagrams that reveal their source on focus.

⌨️ Familiar shortcuts

Cmd/Ctrl+B I K F Z, Tab indent.

⚔️ Cross-platform

Available as a VSCode extension, desktop app (Linux, macOS, windows), android app, and npm package.

🏡 Fully local

No telemetry, no remote server. Bring your own cloud. Your notes stay on your machine, where they belong.
